# SafeHome — Aula 06

## Tema
Requisitos funcionais e não funcionais

## Situação do projeto
O SafeHome contém decisões e artefatos legados possivelmente incompletos ou inadequados ao conteúdo desta aula. O aluno deve analisar o estado atual antes de modificar.

## O que o aluno deve fazer
1. refinar requisitos de leitura, comando, automação, alerta e integração com fabricantes;
2. definir critérios verificáveis;
3. identificar segurança, desempenho, disponibilidade e manutenibilidade;
4. criar matriz de rastreabilidade.

## Dicas
- 'Responder rapidamente' precisa de critério.
- Considere segurança dos comandos remotos.

## Evidências mínimas
- Issue `Aula 06`;
- branch sugerida `aula-06`;
- commits explicativos;
- README/Markdown com problema observado, alteração realizada e critério de aceitação;
- evidência de compilação/teste quando houver código;
- PR ou revisão equivalente quando aplicável.

## Prazo operacional
O trabalho deve começar em sala e ser concluído até o início da aula seguinte, salvo orientação diferente do professor.
