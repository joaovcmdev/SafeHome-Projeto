# Requisitos iniciais — legado

1. O sistema deve ler sensores.
2. Deve controlar dispositivos.
3. Deve permitir automações.
4. Deve emitir alertas.
5. Deve integrar equipamentos de diferentes fabricantes.
6. Deve funcionar mesmo com muitos dispositivos.
7. Deve ser seguro.
8. Deve responder rapidamente.
9. Deve permitir comandos remotos.
10. Deve ser fácil adicionar novos fabricantes.

Os requisitos não possuem critérios de aceitação suficientes.
